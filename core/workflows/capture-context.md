# Capture context

Use when the user explicitly asks to save, remember, update or correct context.

1. Identify whether the content is durable, temporary or sensitive.
2. Reject secrets and propose a non-sensitive description when useful.
3. Search the relevant context file for duplicates or conflicts.
4. Classify the scope as global or a named project.
5. Show the proposed destination, state, wording, source, date and any superseded record.
6. Wait for approval.
7. Apply only the approved change.
8. Read back the updated section and report it.

If the user says not to save, keep the information in the current conversation only.
