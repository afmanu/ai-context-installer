# Prepare brief

Use for a situation, priority or daily work brief. This workflow is read-only unless the user separately requests an update.

1. Read confirmed profile and boundaries.
2. Read current priorities and active projects.
3. Read relevant decisions and open inbox items.
4. Produce:
   - current focus;
   - active projects and next steps;
   - blockers and unknowns;
   - decisions affecting the work;
   - suggested actions, clearly labeled as suggestions.
5. Cite the source file and section for each material fact.

Do not present an inferred deadline, priority or project state as confirmed.
