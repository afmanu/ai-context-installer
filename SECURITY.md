# Security

AI Context Installer stores approved context as local Markdown files. It does not provide encryption, access control, cloud synchronization or secret management.

Never store passwords, API keys, access tokens, private keys, seed phrases, recovery codes or authentication cookies in the context workspace.

The installer must stay inside the approved destination. It must not modify global Claude, Codex, shell, Git or operating-system configuration.

Report security issues privately to the repository owner. Do not include real context files, credentials or complete private paths in public issues.
