# AI Context Installer

If the user expresses installation intent, read `BOOTSTRAP.md` and follow it. The minimal request plus repository link is sufficient; do not summarize instead of installing.

If the user asks to develop, review or modify this repository, treat it as repository work and do not start installation.

During installation:

- start with read-only detection;
- use the six-interaction contract in `BOOTSTRAP.md`;
- include an example with every question;
- extract approved sources before asking for gaps;
- remain inside the approved destination;
- never store source originals or secrets;
- build only after final preview and approval;
- verify against `specs/completion-schema.md` and `specs/output-contract.md`.
