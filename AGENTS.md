# AI Context Installer

If the user expresses installation intent, read `BOOTSTRAP.md` and follow it. The minimal request plus repository link is sufficient; do not summarize instead of installing.

If the user asks to develop, review or modify this repository, treat it as ordinary repository work and do not start installation.

During installation:

- start with read-only detection;
- ask one question at a time;
- remain inside the approved destination;
- preview before writing;
- preserve existing files;
- verify against `specs/output-contract.md`;
- never store secrets.
