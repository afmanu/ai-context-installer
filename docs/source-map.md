# Source map

AI Context Installer is an independent package. It adapts product patterns developed by the same author without creating runtime dependencies on those repositories.

| Capability | Source experience | Adaptation here |
|---|---|---|
| Conversation contract, phases, state and transition gates | `structured-conversation-protocol` | Six-interaction profile protocol with deterministic completion |
| Confirmed context, corrections and scoped facts | `manu-control-center` | Field-level status and provenance |
| Preview, preservation and installation reporting | `manu-control-center` | New-folder installer with readback verification |
| Installation lifecycle and consent boundaries | `agent-guided-installer-framework` | Bundled consent and state checkpoints |
| Minimal prompt, recovery and handoff | `claude-obsidian-second-brain-installer` | Provider-neutral bootstrap without second-brain storage |
| Evidence, authority and boundary distinctions | `manukit` | Source hierarchy and candidate-claim rules |

No source repository is required after installation. Text and structures in this repository are maintained as their own product implementation.
