# Source map

AI Context Installer is an independent package. It adapts product patterns previously developed by the same author without creating runtime dependencies on those repositories.

| Capability | Source experience | Adaptation here |
|---|---|---|
| Confirmed context, corrections and scoped facts | `manu-control-center` | Minimal Markdown context schema |
| Preview, preservation and installation reporting | `manu-control-center` | New-folder installer with no overwrite path |
| Installation lifecycle and consent boundaries | `agent-guided-installer-framework` | Compact bootstrap and state machine |
| Minimal prompt, recovery and handoff | `claude-obsidian-second-brain-installer` | Provider-neutral context installer |
| Evidence, authority and boundary distinctions | `manukit` | Operating rules for confirmed, proposed and unknown context |

No source repository is required after installation. Text and structures in this repository are maintained here as their own product implementation.
