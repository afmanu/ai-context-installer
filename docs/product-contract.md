# Product contract

## Outcome

Create a local workspace that lets a compatible AI agent recover user-approved operating context without relying on chat history or a proprietary memory service.

## Primary user

A knowledge worker who uses Claude or Codex and repeatedly has to explain their role, priorities, active projects and collaboration preferences.

## Success criteria

A new agent session opened in the installed folder can:

1. describe the user's confirmed role and responsibilities;
2. identify current priorities and active projects;
3. distinguish confirmed facts from unknowns and proposals;
4. respect recorded boundaries;
5. prepare a sourced situation brief;
6. resume a recorded project without inventing progress.

## Product boundary

The product stores explicit context in local Markdown. It does not automatically apply to unrelated chats, import chat history, observe user behavior, connect external accounts, modify global agent settings or provide encryption.

## Initial support

- New dedicated destination folders.
- Claude Code, Claude Co-Work with local access and Codex.
- Manual or agent-assisted installation from a local repository copy.
- Spanish or English user content.

Existing-workspace adoption, synchronization and additional runtimes require later evidence.
