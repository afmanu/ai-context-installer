# Resume work

Use when the user asks where work stopped or wants to continue a named project.

1. Resolve the exact project section in `PROJECTS.md`.
2. Read decisions and priorities that explicitly reference that project.
3. Report the confirmed outcome, latest completed result, current state, blockers, next step and open questions.
4. Point to any existing deliverable instead of regenerating it.
5. Suggest the smallest useful continuation and wait for the user's instruction before executing it.

If the project is absent or ambiguous, say so and ask one focused question. Never invent progress from a project name.
