# Guía rápida

## Instalación

Abre Claude Code, Claude Co-Work con acceso a carpetas locales o Codex y envía únicamente:

```text
Quiero instalar mi contexto para IA:

https://github.com/afmanu/ai-context-installer
```

El agente debe leer `BOOTSTRAP.md` e iniciar automáticamente una comprobación de solo lectura.

Después te pedirá:

1. La carpeta nueva donde quieres instalar el contexto.
2. Tu rol y responsabilidades.
3. Tus tres prioridades actuales.
4. Tus proyectos activos.
5. Cómo prefieres trabajar con una IA.
6. Qué límites debe respetar.

Antes de crear los archivos mostrará una previsualización completa. Podrás corregirla y aprobarla.

## Primera prueba

Abre la carpeta instalada con Claude o Codex y pregunta:

```text
Prepárame un brief de situación utilizando únicamente mi contexto confirmado.
```

El agente debe utilizar tus prioridades y proyectos, marcar lo desconocido y citar los archivos consultados.

## Límites

El contexto no se aplica automáticamente a todos tus chats. Debes abrir o adjuntar la carpeta instalada. La primera versión tampoco importa conversaciones, modifica configuraciones globales ni conecta servicios externos.
