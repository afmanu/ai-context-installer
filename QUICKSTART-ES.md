# Guía rápida

## Instalación

Abre Claude Code, Claude Co-Work con acceso a carpetas locales o Codex y envía:

```text
Quiero instalar mi contexto para IA:

https://github.com/afmanu/ai-context-installer
```

El agente leerá `BOOTSTRAP.md` y comenzará automáticamente. No necesitas conocer los archivos internos.

La creación del perfil utiliza un máximo de seis respuestas:

1. Responder las preguntas iniciales, elegir destino y autorizar el estado recuperable.
2. Aportar de una vez CV, documentos, webs, redes, repositorios y ejemplos.
3. Resolver únicamente los huecos y contradicciones detectados.
4. Corregir o confirmar el contrato de colaboración propuesto.
5. Elegir entre ejemplos de calibración y cerrar cualquier campo restante.
6. Revisar y aprobar el perfil completo.

Las fuentes rellenan la mayor parte del perfil. El sistema no debe repetir como pregunta lo que ya pueda extraer con evidencia.

## Primera prueba

Abre la carpeta instalada con Claude o Codex y pregunta:

```text
Lee mi perfil y dime cómo debes colaborar conmigo antes de empezar una tarea.
```

El agente debe describir las reglas confirmadas, distinguir hechos de inferencias y respetar las aprobaciones registradas.

## Límites

El perfil no es un second brain: no guarda proyectos, tareas, notas, decisiones históricas ni conversaciones. Tampoco se aplica automáticamente a chats que no tengan acceso a la carpeta instalada.
